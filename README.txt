HOW TO PUBLISH ON GITHUB PAGES
1. Open https://github.com/Ramsetu11/ram-setu-enterprises
2. Upload/replace index.html in the repository root.
3. Upload the complete images folder (keep the filenames and folder structure exactly as provided).
4. Commit the changes to the main branch.
5. Wait a minute or two, then refresh https://ramsetu11.github.io/ram-setu-enterprises/

Important: Upload index.html AND the images folder. If you upload only index.html, the logo and portraits will not load.
